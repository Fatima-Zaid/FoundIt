### Description
 A simple lost & found board for a theme park. Post lost or found items with a photo, description, date, and time. Visitors can comment to help reconnect items with their owners.
### ***Technologies***
* CSS
* node.js
* HTML
* Mongoose
* express
* ejs
* Visual Studio Code
